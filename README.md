# MetaChain

MetaChain enables hyper-distributed, auto-scaling architecture through adaptive sharding, establishing a resilient, real-time data transmission chain across the network.

MetaChain is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaChain.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
